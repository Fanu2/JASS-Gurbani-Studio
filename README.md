# JASS GURBANI STUDIO

A simple, beautiful PySide6 desktop application for creating Gurbani quote artwork and exporting it as PNG images.

JASS GURBANI STUDIO is designed as a practical visual composer: enter Gurbani text, arrange it on a canvas, adjust typography, preview the result, and save the finished artwork.

## ✨ Features

- **PySide6 desktop application**
- **Gurmukhi Gurbani text rendering**
- Adjustable Gurbani font size
- Text positioning directly on the canvas
- **Drag to move text**
- **Resize text using the canvas handle**
- Text rotation support
- Layer-based composition
- Gurbani, translation/subtitle and watermark layers
- Layer visibility and selection
- Live preview
- Multiple visual themes
- Gradient backgrounds
- Decorative frame option
- PNG image export
- Configurable canvas size
- Gurmukhi font selection
- Latin font support for subtitles and metadata
- Dark, modern application interface
- Single-file application for easy use and sharing

## ▶️ Running the Application

Make sure Python and PySide6 are installed.

```powershell
pip install PySide6 Pillow
```

Then run:

```powershell
py jass_gurbani_studio_v1_7_visual_fixed2.py
```

On systems where `python` is the preferred command:

```bash
python jass_gurbani_studio_v1_7_visual_fixed2.py
```

## 🎨 Basic Workflow

1. Start **JASS GURBANI STUDIO**.
2. Enter or load your Gurbani text.
3. Select the desired canvas/theme.
4. Adjust the Gurbani font size.
5. Drag the text to the desired position.
6. Resize it using the canvas handle.
7. Rotate when required.
8. Adjust title, subtitle/translation and watermark layers.
9. Preview the composition.
10. Save the final image as PNG.

## 📐 Large Text

The canvas is intended to support large Gurbani typography.

For testing and composition, try progressively larger sizes such as:

```text
80 px
100 px
120 px
150 px
180 px
```

Longer Gurbani passages can be used to check wrapping, positioning and visual balance.

JASS GURBANI STUDIO focuses on:

- Simplicity

- Respectful presentation of Gurbani
